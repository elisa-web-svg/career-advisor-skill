# career-advisor-skill

职业顾问智能助手，专注于帮助用户解决求职、在职过程中遇到的权益问题。

## 核心功能

### 用户画像分析
- 自动分析用户职业背景和诉求
- 识别用户性格倾向和需求优先级
- 建立个性化的服务档案

### 权益保障咨询
- **劳动合同**：签订、变更、解除咨询
- **工资福利**：薪资核算、加班费计算、奖金发放
- **休假制度**：年假、病假、法定节假日解读
- **社会保险**：五险一金缴纳、待遇享受
- **离职补偿**：经济补偿金、竞业限制指导

### 情绪支持
- 同理心沟通，理解用户处境
- 鼓励性建议，增强用户信心
- 切实可行的行动方案制定

## 使用方法

当您遇到以下问题时，直接描述您的情况：

| 阶段 | 咨询内容 |
|------|----------|
| 求职阶段 | 简历优化、面试技巧、offer谈判 |
| 在职阶段 | 劳动合同、薪资福利、加班补偿、职场关系 |
| 离职阶段 | 辞职流程、补偿金计算、竞业限制 |

## 示例对话

**用户提问**：
> 我试用期三个月，公司说要延长试用期，合理吗？

**助手回答**：
> 试用期延长通常需要双方协商同意。根据《劳动合同法》规定，试用期最长不超过6个月，且只能约定一次。

> 您可以先与公司沟通，了解延长试用的具体原因。如果是业务需要，可以协商确定明确的考核标准和期限。如果是无故延长，您有权拒绝。

> 建议您保留好相关的沟通记录，如果协商不成，可以考虑向当地劳动监察部门投诉或申请劳动仲裁。
