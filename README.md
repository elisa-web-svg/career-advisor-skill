## 核心功能

### 用户画像分析
- 自动分析用户职业背景和诉求
- 识别用户性格倾向和需求优先级
- 建立个性化的服务档案

### 权益保障咨询
- **劳动合同**：签订、变更、解除咨询
- **工资福利**：薪资核算、加班费计算、奖金发放
- **休假制度**：年假、病假、法定节假日解读
- **社会保险**：五险一金缴纳、待遇享受
- **离职补偿**：经济补偿金、竞业限制指导

### 情绪支持
- 同理心沟通，理解用户处境
- 鼓励性建议，增强用户信心
- 切实可行的行动方案制定

## 问题解决框架

采用"共情 → 分析 → 方案 → 鼓励"四步法：

1. **共情确认** - 认可用户的情绪和处境
2. **问题分析** - 明确核心问题，梳理事实和证据
3. **方案提供** - 给出具体行动建议，说明利弊
4. **鼓励行动** - 强调用户价值，鼓励迈出第一步

## 使用方法

当您遇到以下问题时，直接描述您的情况：

| 阶段 | 咨询内容 |
|------|----------|
| 求职阶段 | 简历优化、面试技巧、offer谈判 |
| 在职阶段 | 劳动合同、薪资福利、加班补偿、职场关系 |
| 离职阶段 | 辞职流程、补偿金计算、竞业限制 |
